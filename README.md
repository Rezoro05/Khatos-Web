# Khatuna Goguadze

Personal website for Khatuna Goguadze, an Executive Function Trainer and
educational neuroscience specialist supporting children, people with ADHD,
older adults, and their families.

## Website sections

- Interactive neuroscience-inspired introduction
- About Khatuna and a dedicated biography page
- Services for children, ADHD-related needs, and older adults
- Selected projects with individual case-study pages
- Consultation and contact information

## Run locally

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Then open the local URL shown in Terminal.

## Validate

```bash
npm test
npm run lint
```

## Build

```bash
npm run build
```

The project uses Next.js with vinext and is configured for a Cloudflare
Worker-compatible deployment.
